# CO-GOAL 数据字典

> 小程序（患者端）后端数据库 · MySQL 8.0 / utf8mb4
> 对应 SQL：`sql/001_wechat_user_tables.sql`（可重复执行，先 DROP 后 CREATE）
> 维护规则：**改表结构 = 改 001 SQL + 更新本文件 + 重新导入**，三者同步

## 一、表总览与关系

```
user_account（用户账号） 1 ──── n user_auth（登录凭证）
user_account（用户账号） 1 ──── 1 patient_profile（患者档案）

无外键约束，一致性由应用层（AuthService 事务等）保证。
```

| 表 | 说明 | 对应小程序功能 |
|---|---|---|
| `user_account` | 登录主体：token、资料、登录统计 | 登录页、个人资料 |
| `user_auth` | 登录凭证：openid/手机号/邮箱/用户名 | 登录页 |
| `patient_profile` | 患者健康档案 | 基础信息 Tab |

## 二、user_account（用户账号表）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| user_id | BIGINT UNSIGNED | 自增 PK | 用户ID |
| nickname | VARCHAR(64) | '' | 微信昵称；登录时为空，授权资料后更新 |
| avatar | VARCHAR(255) | '' | 头像 URL；chooseAvatar 后需上传存储 |
| gender | TINYINT | 0 | 性别：0未知 / 1男 / 2女（手选，微信不再提供性别授权） |
| phone | VARCHAR(20) | '' | 手机号；getPhoneNumber 授权→code→服务端换号写入 |
| api_token | VARCHAR(64) | '' | 登录 token（64 位 hex）；**每次登录重签，旧 token 失效**（单点登录） |
| token_expired_at | INT UNSIGNED | 0 | token 过期时间（Unix 秒），默认 +30 天 |
| session_key | VARCHAR(64) | '' | 微信会话密钥（敏感，预留解密用） |
| last_login_at | INT UNSIGNED | 0 | 最近登录时间（Unix 秒） |
| login_count | INT UNSIGNED | 0 | 累计登录次数 |
| status | TINYINT | 1 | 1正常 / 0禁用（禁用即踢下线） |
| created_at | INT UNSIGNED | 0 | 创建时间，TimestampBehavior 自动 |
| updated_at | INT UNSIGNED | 0 | 更新时间，TimestampBehavior 自动 |

索引：`PRIMARY(user_id)`、`idx_phone(phone)`、`idx_token(api_token)`

## 三、user_auth（登录凭证表）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| auth_id | BIGINT UNSIGNED | 自增 PK | 凭证ID |
| user_id | BIGINT UNSIGNED | — | → user_account.user_id（1:n） |
| identity_type | VARCHAR(20) | — | wechat / phone / email / username（目前仅 wechat 启用） |
| identifier | VARCHAR(128) | — | wechat=openid；phone=手机号；email=邮箱；username=登录名 |
| credential | VARCHAR(255) | '' | 密码哈希（bcrypt）；仅 email/username 用，其余为空 |
| created_at / updated_at | INT UNSIGNED | 0 | 自动填充 |

约束：`UNIQUE(identity_type, identifier)` —— 同一登录方式下标识唯一；`idx_user(user_id)`

## 四、patient_profile（患者档案表）—— 小程序「基础信息」Tab 对照

| 字段 | 类型 | 默认 | 小程序界面 | 取值字典 |
|---|---|---|---|---|
| profile_id | BIGINT UNSIGNED | 自增 PK | — | — |
| user_id | BIGINT UNSIGNED | — | — | 唯一（1:1） |
| age | TINYINT UNSIGNED | 0 | 个人与诊断档案 · 年龄输入框 | 单位：岁 |
| dx_status | VARCHAR(16) | '' | 个人与诊断档案 · 诊断状态单选 | 初诊 / 复发 |
| ecog | TINYINT | 0 | 体能自评 · ECOG 单选 | 0正常 / 1轻 / 2卧床<50% / 3卧床>50% / 4全卧 |
| hctci | JSON | NULL | 体能自评 · 合并症多选 chips | 高血压 / 糖尿病 / 肾功能不全 / 房颤 / 心衰 / 慢阻肺 / 既往实体瘤 |
| mutations | JSON | NULL | 分子与风险档案 · 基因变异多选 | NPM1 / FLT3-ITD / DNMT3A / IDH1 / IDH2 / TP53 / RUNX1 / ASXL1 |
| fit_status | VARCHAR(16) | '' | 体能自评 · 徽标（服务端重算） | fit / unfit |
| eln_risk | VARCHAR(16) | '' | 分子与风险档案 · 徽标（服务端重算） | 低危 / 中危 / 高危 |
| prognosis_expect | TINYINT UNSIGNED | 0 | 预后校准 · 滑块 | 0–100（%） |
| created_at / updated_at | INT UNSIGNED | 0 | — | 自动填充 |

约束：`UNIQUE(user_id)`

### 服务端重算规则（ProfileService，不信任前端）

**fit_status**（满足任一即 unfit）：
```
ECOG ≥ 3  或  HCT-CI 选中 ≥ 3 项  或  年龄 ≥ 75
```

**eln_risk**（ELN 2022 简化版）：
```
含 TP53                → 高危
NPM1 + FLT3-ITD        → 中危（2022 版已取消比值区分）
仅 NPM1                → 低危
其他组合               → 中危
```

## 五、关键流程

### 登录（登录即注册）

```
小程序 wx.login → code
  → POST /wechat_patient/login
    → code2session 换 openid + session_key
    → 查 user_auth(wechat, openid)
        ├ 有 → 老用户，读 user_account 校验 status
        └ 无 → 事务：INSERT user_account + user_auth（时间戳自动填充）
    → 重签 api_token（+30 天）、更新 last_login_at/login_count/session_key
    → 返回 { token, isNewUser, hasProfile }
```

### API 鉴权

```
除 /wechat_patient/login 外所有接口：
请求头 X-Api-Token: <token>
→ 查 user_account.api_token → validateToken()（存在+未过期+status=1）
→ 失败返回 { code:401 }
```

## 六、时间字段约定

- 所有时间字段为 **INT UNSIGNED，存 Unix 秒级时间戳**
- 由 `TimestampBehavior` 自动维护（模型：app\models\UserAccount / UserAuth / PatientProfile）
- 查询展示：`FROM_UNIXTIME(created_at)`；PHP：`date('Y-m-d H:i:s', $ts)`
